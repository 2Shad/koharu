<Steps>
  <Step title="Choose a release">
    Open the [latest GitHub release](https://github.com/koharu-rs/koharu/releases/latest) and select the package for your operating system and processor.

    <Tabs>
      <Tab title="Windows">
        Run the Windows installer from the release, or install with WinGet:

        ```powershell
        winget install koharu
        ```
      </Tab>
      <Tab title="macOS">
        Choose the Apple-silicon release and place Koharu in Applications, or install with Homebrew:

        ```bash
        brew install --cask koharu
        ```
      </Tab>
      <Tab title="Linux">
        Choose the package for your distribution and processor. Install any desktop-library dependencies reported by your package manager.
      </Tab>
      <Tab title="Android">
        Download the `arm64-v8a` APK and open it from your browser or file manager; the first install asks you to allow installing apps from that source. The APK targets Android 12 (API 31) and newer.
      </Tab>
    </Tabs>

  </Step>
  <Step title="Let the runtime initialize">
    Launch Koharu and wait for the project browser. First launch can take longer while native packages download. Model files download when you first use the selected model.

    Runtime packages come from GitHub release assets, PyPI for CUDA, and AMD's repository for ROCm; model weights come from Hugging Face. Keep the app open while downloads finish; the activity center shows progress.

  </Step>
  <Step title="Create your first project">
    Follow the [quickstart](/quickstart) with one readable manga page. Check [hardware and runtimes](/hardware) if device initialization fails.
  </Step>
</Steps>

## Install updates

Release builds check a signed GitHub release feed once at startup; there is no manual update check. When an update is offered, let the download complete before Koharu relaunches.

<Tip>
  Use a release build for translation work. Use the [development setup](/development/setup) when
  you want to change Koharu's code.
</Tip>

## Android

Sideload the APK: download it, open it from your browser or file manager, and allow installation from that app when Android prompts you. The build is `arm64-v8a` only and needs Android 12 (API 31) or newer.

The first Android release is fully offline. Detection, OCR, translation, and inpainting run on-device, so no network is required after the model weights are in place. The native runtimes — llama.cpp (`libllama`, `libmtmd`) and LibTorch (`libtorch_cpu`, `libkoharu-torch`) — are bundled in the APK and loaded from the app's native library directory. Koharu never downloads executable code on Android; only model weights are fetched, when you first use a model.

### Supported devices

Koharu needs a 64-bit ARM phone with at least 6 GB of RAM. The pipeline keeps one model stage resident at a time, so peak memory tracks the largest single model rather than their sum.

| Device class | RAM   | Translation         | Status                        |
| ------------ | ----- | ------------------- | ----------------------------- |
| Mid-range    | 8 GB  | Gemma 4 E4B Q2_K_XL | Pending reference-device run  |
| Flagship     | 12 GB | Gemma 4 E4B Q4_K_XL | Pending reference-device run  |
| Floor        | 6 GB  | Gemma 4 E2B Q2_K_XL | Pending reference-device run  |

The numbers above are the planned targets, not measured results. See [hardware and runtimes](/hardware#android) for the full profile table and the benchmark harness.
