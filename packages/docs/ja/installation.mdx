<Steps>
  <Step title="リリースを選ぶ">
    [最新の GitHub リリース](https://github.com/koharu-rs/koharu/releases/latest)から、OS とプロセッサーに合うパッケージを選びます。

    <Tabs>
      <Tab title="Windows">
        Windows インストーラーを実行するか、WinGet を使います。

        ```powershell
        winget install koharu
        ```
      </Tab>
      <Tab title="macOS">
        Apple シリコン向けのリリースを選んで Koharu をアプリケーションフォルダーへ移動するか、Homebrew を使います。

        ```bash
        brew install --cask koharu
        ```
      </Tab>
      <Tab title="Linux">
        ディストリビューションとプロセッサーに合うパッケージを選びます。パッケージマネージャーが要求するデスクトップライブラリもインストールしてください。
      </Tab>
      <Tab title="Android">
        `arm64-v8a` の APK をダウンロードし、ブラウザーまたはファイルマネージャーから開きます。初回はインストール元アプリからのインストールを許可するよう求められます。対象は Android 12（API 31）以降です。
      </Tab>
    </Tabs>

  </Step>
  <Step title="ランタイムの初期化を待つ">
    Koharu を起動し、プロジェクト一覧が表示されるまで待ちます。初回はネイティブパッケージの取得に時間がかかることがあります。モデル本体は選択したモデルを初めて使う際に取得されます。

    ランタイムパッケージは GitHub のリリースアセットから、CUDA 用は PyPI から、ROCm 用は AMD のリポジトリから取得し、モデルの重みは Hugging Face から取得します。アクティビティセンターで進捗を確認し、完了までアプリを開いたままにします。

  </Step>
  <Step title="プロジェクトを作る">
    読みやすいマンガ画像を 1 枚用意し、[クイックスタート](/ja/quickstart)へ進みます。デバイス初期化に失敗した場合は[ハードウェア](/ja/hardware)を確認してください。
  </Step>
</Steps>

## アップデート

リリース版は起動時に一度だけ署名付きの GitHub 更新フィードを確認します。手動での更新確認はありません。更新が表示されたら、Koharu が再起動する前にダウンロードの完了を待ちます。

<Tip>
  翻訳作業にはリリース版を使います。コードを変更する場合は[開発環境のセットアップ](/ja/development/setup)を参照してください。
</Tip>

## Android

APK をサイドロードします。ダウンロードしてブラウザーまたはファイルマネージャーから開き、Android の確認が出たらインストール元アプリからのインストールを許可してください。ビルドは `arm64-v8a` のみで、Android 12（API 31）以降が必要です。

初回の Android リリースは完全にオフラインで動作します。検出、OCR、翻訳、インペイントはすべて端末上で実行されるため、モデルの重みを用意したあとにネットワークは不要です。llama.cpp（`libllama`、`libmtmd`）と LibTorch（`libtorch_cpu`、`libkoharu-torch`）のネイティブランタイムは APK に同梱され、アプリのネイティブライブラリディレクトリから読み込まれます。Android で実行可能コードをダウンロードすることはありません。取得するのはモデルの重みだけで、初めてモデルを使うときにダウンロードされます。

### 対応デバイス

64 ビット ARM の端末と 6 GB 以上の RAM が必要です。パイプラインは同時に 1 つのステージだけを常駐させるため、ピークメモリは合計ではなく最大の単一モデルに収まります。

| デバイスクラス | RAM   | 翻訳                | 状態                       |
| -------------- | ----- | ------------------- | -------------------------- |
| ミッドレンジ   | 8 GB  | Gemma 4 E4B Q2_K_XL | 参照端末での計測待ち       |
| ハイエンド     | 12 GB | Gemma 4 E4B Q4_K_XL | 参照端末での計測待ち       |
| 下限           | 6 GB  | Gemma 4 E2B Q2_K_XL | 参照端末での計測待ち       |

上記は目標値であり、実測値ではありません。プロファイル一覧とベンチマークハーネスは[ハードウェアとランタイム](/ja/hardware#android)を参照してください。
