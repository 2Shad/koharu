<Steps>
  <Step title="选择发行版">
    打开[最新 GitHub 发行版](https://github.com/koharu-rs/koharu/releases/latest)，选择适合操作系统与处理器的安装包。

    <Tabs>
      <Tab title="Windows">
        运行 Windows 安装程序，或使用 WinGet：

        ```powershell
        winget install koharu
        ```
      </Tab>
      <Tab title="macOS">
        选择 Apple 芯片版本并将 Koharu 放入“应用程序”文件夹，或使用 Homebrew：

        ```bash
        brew install --cask koharu
        ```
      </Tab>
      <Tab title="Linux">
        选择适合发行版和处理器的软件包，并安装包管理器提示缺少的桌面库。
      </Tab>
      <Tab title="Android">
        下载 `arm64-v8a` 的 APK，然后从浏览器或文件管理器打开。首次安装时 Android 会要求允许来自该来源的应用安装。该版本面向 Android 12（API 31）及更高版本。
      </Tab>
    </Tabs>

  </Step>
  <Step title="等待运行时初始化">
    启动 Koharu，等待项目列表出现。首次启动可能需要下载原生运行时，因此耗时较长。模型文件会在首次使用所选模型时下载。

    运行时软件包来自 GitHub 发行资源、CUDA 对应的 PyPI 以及 ROCm 对应的 AMD 仓库；模型权重来自 Hugging Face。活动中心会显示进度，请保持应用打开直到完成。

  </Step>
  <Step title="创建项目">
    准备一张清晰的漫画图片，按照[快速开始](/zh/quickstart)操作。如果设备初始化失败，先查看[硬件与运行时](/zh/hardware)。
  </Step>
</Steps>

## 安装更新

发行版会在启动时检查一次带签名的 GitHub 更新源，没有手动检查更新的功能。出现更新提示后，请等待下载完成，之后 Koharu 会重新启动。

<Tip>日常翻译使用发行版。需要修改代码时，请参考[开发环境](/zh/development/setup)。</Tip>

## Android

通过侧载安装 APK：下载后从浏览器或文件管理器打开，并在 Android 提示时允许来自该来源的应用安装。该构建仅支持 `arm64-v8a`，需要 Android 12（API 31）或更高版本。

首个 Android 发行版完全离线运行。检测、OCR、翻译和修补均在设备上执行，准备好模型权重后无需网络。llama.cpp（`libllama`、`libmtmd`）与 LibTorch（`libtorch_cpu`、`libkoharu-torch`）等原生运行时随 APK 一同打包，并从应用的本地库目录加载。Koharu 在 Android 上不会下载可执行代码，只会在首次使用模型时获取模型权重。

### 支持的设备

需要 64 位 ARM 手机和至少 6 GB 内存。管线一次只常驻一个阶段模型，因此峰值内存取决于最大的单个模型，而非总和。

| 设备等级 | RAM   | 翻译                | 状态             |
| -------- | ----- | ------------------- | ---------------- |
| 中端     | 8 GB  | Gemma 4 E4B Q2_K_XL | 待参考设备实测   |
| 旗舰     | 12 GB | Gemma 4 E4B Q4_K_XL | 待参考设备实测   |
| 下限     | 6 GB  | Gemma 4 E2B Q2_K_XL | 待参考设备实测   |

上表为目标值而非实测结果。完整的配置表与基准测试工具见[硬件与运行时](/zh/hardware#android)。
